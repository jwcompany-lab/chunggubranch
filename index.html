📱 핸드폰 실시간 연동 및 구글 시트 연결

여러 대의 스마트폰과 PC에서 출결 데이터를 실시간 공유합니다.

🚀 방법 1: 현재 화면 설정(지점구분·명단) 그대로 깃허브 배포용 HTML 저장 가장 간편

깃허브(GitHub Pages)는 기본 상태에서는 수정한 내용이 본인 브라우저에만 저장됩니다. 화면에서 지점구분 삭제·변경, 명단 수정, 구글시트 연동 주소 입력을 마친 뒤 아래 버튼을 눌러 저장된 index.html을 깃허브에 덮어쓰기하시면 접속하는 모든 사람에게 똑같은 지점구분과 명단이 기본값으로 바로 보입니다.

🔗 방법 2: 구글 시트 실시간 양방향 DB 연동 (여러 사람 동시 수정·출결 공유) 실시간 자동동기화

깃허브에 파일을 다시 올리지 않고도 누군가 지점구분을 바꾸거나 출결을 체크했을 때 다른 사람 폰에도 실시간으로 반영되게 하려면 구글 시트 웹앱 URL을 연결하세요.

  1. 새 구글 스프레드시트를 열고 상단 메뉴 [확장 프로그램] → [Apps Script] 클릭
  2. 아래 [구글시트 연동용 스크립트 복사] 버튼을 눌러 코드를 붙여넣고 저장
  3. 우측 상단 [배포] → [새 배포] → 유형: 웹 앱 (액세스 권한: 모든 사용자) 배포 후 생성된 URL을 아래에 입력 후 [연동 주소 저장] 클릭
📲 파일로 다른 핸드폰/PC에 즉시 내보내기 · 불러오기

현재 등록된 지점구분, 설계사 명단과 전체 출결 기록(JSON)을 카톡이나 파일로 주고받아 그대로 복원할 수 있습니다.
